# Автоматизация тестов для Кинопоиска

Проект автоматизации UI и API тестов для сайта Кинопоиск (https://www.kinopoisk.ru/).

## 📋 Описание проекта

Этот проект содержит автоматизированные тесты для проверки функциональности сайта Кинопоиск:
- UI тесты: проверка главной страницы, поиска, навигации, страниц фильмов
- API тесты: тестирование публичного API Кинопоиска

## 🚀 Быстрый старт

### Предварительные требования
- Python 3.8 или выше
- Google Chrome браузер
- API ключ Кинопоиска (можно получить на https://api.kinopoisk.dev/)
