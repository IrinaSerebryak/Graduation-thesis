# Автоматизация тестов для Кинопоиска

## Описание проекта
Проект содержит автоматизированные UI и API тесты для сайта Кинопоиск (https://www.kinopoisk.ru/).

## Тестовое покрытие

### API тесты (10 тестов):
1. Получение фильма по ID
2. Поиск фильмов по названию
3. Фильтрация фильмов по году
4. Фильтрация фильмов по рейтингу
5. Получение случайного фильма
6. Получение фильмов из Топ 250
7. Получение актеров фильма
8. Получение информации о сезонах сериала
9. Получение рецензий к фильму
10. Получение похожих фильмов

### UI тесты (10 тестов):
1. Открытие главной страницы
2. Поиск фильмов (параметризованный тест)
3. Переход на страницу фильма
4. Авторизация на сайте
5. Фильтрация результатов поиска
6. Проверка контента страницы фильма
7. Навигация в раздел Топ 250
8. Проверка работы формы поиска
9. Проверка основных элементов сайта
10. Поиск несуществующего фильма (негативный сценарий)
